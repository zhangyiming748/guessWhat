# guessWhat

根据 URL 中已经确定的字符部分，穷举猜出缺失的字符。

## 思路

使用穷举法逐个填充 URL 中未知的字符，每拼出一个候选 URL 就实际发起 HTTP 请求：

- 响应是 **Base64 加密的字符串**（长度 ≥ 8 且不是 JSON）=> 视为命中，这个 URL 是正确的
- 响应是 **JSON 格式**（尤其是包含 `error` 字段）=> 视为错误，继续穷举下一个
- 请求失败、超时、响应为空或过短 => 一律按错误处理，继续穷举

命中后程序会把正确的 URL 追加记录到 `result.txt`，并打印响应内容及 Base64 解码结果，然后退出。

## 使用方法

1. 打开 `main.go`，修改顶部的 `urlTemplate` 常量，把 URL 中不确定的字符用 `*`（星号）代替，例如：

   ```go
   const urlTemplate = "http://example.com/api/****"
   ```

2. 运行程序：

   ```bash
   go run .
   ```

   或先编译再运行：

   ```bash
   go build -o guesswhat .
   ./guesswhat
   ```

3. 程序会按 **每秒 1 个请求** 的频率逐个尝试候选 URL（单个请求超时 10 秒），命中后结果写入 `result.txt`。

## 规则说明

- 占位符 `*` 可取的字符集为：**大写字母、小写字母、数字**，共 62 种
- 支持多个 `*`，程序会穷举所有组合（第 `idx` 个组合按 62 进制展开填充，不重复、不遗漏）
- 组合总数 = \(62^n\)（`n` 为占位符数量）：
  - 1 个占位符：62 种，约 1 分钟
  - 2 个占位符：3844 种，约 1 小时
  - 3 个占位符：约 23.8 万种，约 2.7 天
  - 超过 3 个程序会提示耗时极长，超过 10 个直接拒绝运行
- 判定为命中的 Base64 响应会尝试标准 / 无填充 / URL 安全等多种变体解码并展示
- 若 URL 中没有任何 `*`，程序直接退出（退出码 2）

## 环境要求

- Go 1.21+（无第三方依赖）

## CI

仓库自带 GitHub Actions 工作流（`.github/workflows/guesswhat.yml`）：在 push 到 `main`/`master` 或手动触发时，在云端构建并运行穷举任务（最长允许 6 小时），并把 `result.txt` 作为 artifact 上传，可在 Actions 页面下载。

> 注意：占位符较多时穷举耗时可能远超 6 小时，请尽量提供更精确的 URL。
