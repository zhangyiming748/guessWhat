# guessWhat
根据URL已经明确的字符部分猜出来缺失的字符
# 思路
使用使用穷举法拼接字符串中未知的字符部分 然后实际去请求 如果请求到正确的值 就打印出这个正确的值
# 结构
1. 我会输入一个URL 其中URL中不明确的字符用问号代替
2. 问号有可能是大写字母 小写字母 数字
3. 实际的URL可能是有多个问号 每一种可能性都试一下
4. 拿着这个拼接好的URL去HTTP请求一个网址
5. 如果网址返回的是一个 Base64 加密的字符串 那就是正确的值 如果返回一个 JSON 格式 并且 JSON 格式里明确有一个“error”的单词 说明这个 URL 是错误的
6. 把正确的这个URL记录到文本文件里
